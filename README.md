# 골목 맛집 수첩

지도에서 기준 위치를 정하면 반경 3km 안의 맛집을 보여 주는 맛집 추천 페이지 초안입니다.

## 기능
- 카카오맵 장소 API의 '음식점(FD6)'·'카페(CE7)' 카테고리로 반경 500m / 1km / 3km / 5km 안의 실제 가게를 가까운 순으로 불러옴 (한 번에 최대 45곳)
- 고르는 기준: 체인점(지점명이 붙은 곳) 기본 제외, 전화번호·도로명 주소가 등록된 곳만
- 직접 가 본 곳에 별점과 메모를 남기면 ★4 이상이 '내 맛집'으로 표시 (브라우저에 저장, 내보내기/가져오기 지원)
- 카카오맵 / 네이버 지도 전환, 종류 필터, 검색, 폰에서 목록/지도 탭

평점·리뷰 수는 카카오·네이버 공개 API에서 제공하지 않아 쓰지 않습니다.

## 파일
- `index.html` — 지도 연동 버전 (메인)
- `claude-artifact-draft.html` — 지도 없는 초기 초안 (Claude 아티팩트용)

## 설정
`index.html` 위쪽에 키를 넣으세요. 하나만 넣어도 그 지도는 동작합니다.

```js
const NAVER_KEY_ID = "YOUR_NAVER_CLIENT_ID";      // 네이버 클라우드 플랫폼 · Maps Client ID
const KAKAO_JS_KEY = "YOUR_KAKAO_JAVASCRIPT_KEY"; // 카카오 디벨로퍼스 · JavaScript 키
```

- 네이버: Application 등록에서 Maps 선택 → Web 서비스 URL에 배포 주소 등록
- 카카오: 앱 생성 → 플랫폼 Web 사이트 도메인 등록 → 카카오맵 사용 설정 ON
- 로컬 테스트는 `http://localhost`를 등록한 뒤 `npx serve .` 등으로 띄우면 됩니다.

## 데이터
가게 정보는 카카오맵에서 실시간으로 불러옵니다. 카카오 JavaScript 키와 도메인 등록, 카카오맵 사용 설정이 필요합니다.

## 공공데이터 연결 (폐업 · 업력 · 착한가격 · 위생등급)

카카오 결과에 아래 공공데이터를 가게 이름과 주소로 맞춰 붙입니다. 데이터가 없으면 이 기능만 꺼지고 나머지는 그대로 동작합니다.

| 폴더 | 넣을 파일 | 페이지에서 쓰는 곳 |
|---|---|---|
| `data/raw/biz/` | 행정안전부 일반음식점·휴게음식점 인허가 CSV ([공공데이터포털](https://www.data.go.kr/dcat/metadata/15045016)) | 폐업 신고된 곳 숨김, 'N년 된 가게' 배지, 오래된 가게 순 정렬 |
| `data/raw/goodprice/` | 지자체 착한가격업소 현황 CSV (공공데이터포털에서 '착한가격업소' 검색) | '착한가격' 배지, 대표 메뉴와 가격 |
| `data/raw/hygiene/` | 음식점 위생등급 지정 현황 CSV (공공데이터포털에서 '위생등급' 검색) | '위생 ★★★' 배지 |

1. CSV 를 받아 해당 폴더에 넣습니다. 여러 파일, 여러 지역을 섞어도 됩니다. CP949(EUC-KR)·UTF-8 모두 됩니다.
2. 전국 파일처럼 100MB 가 넘으면 필요한 지역만 잘라서 넣습니다.
   `node scripts/slice-csv.mjs 원본.csv data/raw/biz/mapo.csv "서울특별시 마포구"`
3. GitHub 에 올리면 Actions 가 `data/public/` 을 자동으로 다시 만듭니다. 직접 만들려면 `node scripts/build-public-data.mjs`.

헤더 이름이 파일마다 조금씩 달라도 흔한 이름(사업장명/업소명, 도로명전체주소/도로명주소, 지정등급/위생등급 등)은 자동으로 알아봅니다.
인허가 좌표(EPSG:5174)는 WGS84 로 바꿔 주소가 안 맞을 때 60m 안의 같은 이름 가게를 찾는 데 씁니다.
이름·주소로 맞추는 방식이라 일부는 못 찾거나 잘못 맞출 수 있습니다.
